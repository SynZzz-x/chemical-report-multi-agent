# Goal
请根据任务与提供的资料生成专业、准确、可实施的中文内容。

如果生成的内容中包含行内公式，必须使用 Markdown 行内公式格式（$）包裹。

1. **格式严格**：生成内容必须严格遵循 Markdown 语法。
2. **禁止标签**：**严禁**使用 ```markdown``` 或 ``` 标签包裹输出内容。请直接输出 Markdown 纯文本。

6. **无需添加后缀**：生成正文完毕后直接结束，无需添加任何额外的字数或总结信息。
